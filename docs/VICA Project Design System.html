01 · Foundation

Make the work feel welcomed.

VICA’s identity is confident, open, energetic, and grounded. Project experiences should make student work easy to discover without making the student disappear behind the interface.

Clear before clever

Use strong hierarchy, generous space, and plain language so a visitor understands the work, owner, subject, and next action quickly.

People in the picture

Show the maker, collaborators, process, and context. Future photography should feel spontaneous, energetic, high-contrast, and story-led.

Accent with purpose

Keep the page calm and white. Reserve purple, blue, and green for moments that guide attention or signal meaning.

02 · Color system

White is the stage.

The brand guide says the VICA logo should appear against white. Purple and blue are the primary digital accents; complementary colors bring energy to campaigns, categories, and future showcases.

03 · Typography

Readable, modern, human.

The guide names Colaborate for copy and Helvetica Neue for the logotype. On the web, use a close sans-serif fallback stack and preserve the same contrast between expressive headlines and calm body copy.

Classroom ideas. Real-world possibilities.

Use a confident display style for project titles, then keep descriptions short, direct, and easy to scan. Never use typography to imitate or recreate the VICA logo.

Display

Large, tight, expressive headlines. Use for landing pages, project titles, and showcase openings.

Body

Neutral sans-serif at 16px or above for long reading, project summaries, and learning guidance.

Metadata

Small but never faint: dates, subjects, technologies, and status should remain readable and useful.

05 · Apply now

Make today’s ProjectHub feel VICA.

The current implementation should prioritize clarity, ownership, and safe exploration while staying faithful to the brand guide.

Do

  • Keep the default canvas white.
  • Use the official logo without recoloring, rotating, skewing, or recreating it.
  • Use purple for primary actions and blue for supporting links.
  • Keep student work and authors visible together.
  • Maintain generous logo clear space.

Don’t

  • Use a green page-wide wash as the default theme.
  • Turn the VICA mark into a decorative icon or avatar.
  • Use low-contrast gray metadata.
  • Overload project cards with badges and controls.
  • Use imagery that feels staged or disconnected from the story.

Current implementation checklist

  • White default background and VICA palette tokens in src/app/globals.css.
  • Official logo URL used in the site shell and preview.
  • Project discovery routed through Trending after Explore’s removal.
  • Journey, collaboration, and browse-intent patterns included on the homepage.
06 · Build forward

A system that grows with the school.

Treat this artifact as a living contract. New features should extend the same signals rather than invent a new visual language each time.

Student portfolio mode

Let students assemble a curated body of work with a strong cover story, process timeline, and shareable profile.

Class showcase templates

Offer teachers a repeatable layout for end-of-term exhibitions, with subject color variations that remain within the palette.

Impact stories

Pair project outcomes with photography and short quotes so the work communicates its human story without excess copy.

Brand-safe theming

Expose approved color tokens to future tools, emails, dashboards, and public pages so every new surface starts in the right place.
